# Kahuna

A stock analysis web app powered by AI. Search any S&P 500 company, view price charts, and get an AI-generated financial analysis.

## Setup

**Requirements:** Python 3.10+, Node 18+

### 1. Clone and enter the repo

```bash
git clone https://github.com/JTAN-37/kahuna.git
cd kahuna
```

### 2. Backend

```bash
python -m venv venv
source venv/bin/activate       # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Create a `.env` file in the project root:

```
ANTHROPIC_API_KEY=your_key_here
```

### 3. Frontend

```bash
cd frontend
npm install
```

### 4. Fetch S&P 500 data

```bash
python scripts/update_sp500.py
```

This writes `data/sp500.json`, which the backend reads at startup. Re-run it whenever you want to refresh the constituent list.

## Running

Open **two terminals** from the project root:

**Terminal 1 — backend** (port 8000):
```bash
source venv/bin/activate
python -m backend.main
```

**Terminal 2 — frontend** (port 5173):
```bash
cd frontend
npm run dev
```

Open **http://localhost:5173**.

To stop either server, press `Ctrl+C` in its terminal.

## Production build

Builds the frontend as static files and serves everything from FastAPI on port 8000:

```bash
cd frontend && npm run build
source venv/bin/activate
python -m backend.main
```

Open **http://localhost:8000**.

## Project structure

```
kahuna/
├── backend/
│   ├── main.py               # FastAPI app entry point
│   ├── routers/
│   │   ├── stocks.py         # GET /api/sp500, GET /api/stock/{ticker}
│   │   └── analysis.py       # GET /api/analyze/{ticker} (streaming)
│   ├── services/
│   │   ├── sp500.py          # Loads S&P 500 list from data/sp500.json
│   │   └── analysis.py       # Anthropic streaming with prompt caching
│   └── utils/
│       └── tickers.py        # normalize_ticker, logo_url_for
├── frontend/
│   └── src/
│       ├── App.jsx            # Layout shell
│       ├── components/        # Navbar, Sidebar, SidebarTab, StockPanel,
│       │                      # StockChart, AnalysisCard, StockLogo, Icons
│       ├── hooks/             # useStockData, useSP500, useAnalysis
│       ├── store/
│       │   └── watchlist.js   # Zustand: tickers, pins, sidebar state
│       └── utils/
│           └── formatters.js  # fmtPrice, fmtCap, fmtPE
├── data/
│   └── sp500.json             # Generated by scripts/update_sp500.py
├── scripts/
│   └── update_sp500.py        # Fetches S&P 500 list from Wikipedia
└── requirements.txt
```
